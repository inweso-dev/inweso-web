Hosting und Auslieferung

Diese Website wird über GitHub Pages ausgeliefert, einen Dienst der GitHub, Inc., 88 Colin P. Kelly Jr. St., San Francisco, CA 94107, USA. Beim Aufruf einer Seite protokolliert GitHub Ihre IP-Adresse zu Sicherheitszwecken, unabhängig davon, ob Sie bei GitHub angemeldet sind. Wir selbst haben keinen Zugriff auf diese Protokolle. GitHub ist nach dem Swiss-U.S. Data Privacy Framework und dem EU-U.S. Data Privacy Framework zertifiziert. Einzelheiten stehen in der Datenschutzerklärung von GitHub.

Die Namensauflösung (DNS) und die Auslieferung von inweso.ch laufen über Cloudflare, Inc., 101 Townsend St., San Francisco, CA 94107, USA. Cloudflare beantwortet die DNS-Anfragen und leitet die Aufrufe als Reverse-Proxy an GitHub weiter. Dabei bearbeitet Cloudflare technische Verbindungsdaten wie Ihre IP-Adresse und Routing-Daten sowie Fehlerberichte des Browsers (Network Error Logging), um Anfragen auszuliefern und Angriffe abzuwehren. Cloudflare ist nach dem Swiss-U.S. Data Privacy Framework und dem EU-U.S. Data Privacy Framework zertifiziert. Einzelheiten stehen in der Datenschutzerklärung von Cloudflare. Wie lange GitHub und Cloudflare diese Protokolle aufbewahren, steht in den beiden Datenschutzerklärungen.

Keine Cookies, keine Analyse

Diese Website setzt keine Cookies, nutzt keine Analyse- oder Tracking-Dienste, enthält keine Formulare und bindet keine Inhalte von Drittanbietern ein (keine externen Schriften, Skripte oder Videos). Einzig die Wahl zwischen hellem und dunklem Farbschema merkt sich Ihr Browser lokal (localStorage); sie wird nicht an uns übertragen. Für Websites, auf die wir verlinken, gelten deren eigene Datenschutzbestimmungen.
